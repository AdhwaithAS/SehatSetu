# SehatSetu

<p align="center">
  <img src="https://github.com/AdhwaithAS/SehatSetu/blob/production/Sehat(USER)/sehatsetu/public/logo.png" alt="SehatSetu Logo" width="200"/>
</p>

SehatSetu is a **role-based healthcare management platform** that bridges the gap between **patients, doctors, and administrators**.  
It simplifies **medical consultations, appointment booking, and medical record access** through separate portals.

## ✨ Features

### 👤 User Portal
- Secure patient registration and login
- Book and manage appointments
- View medical history & prescriptions

### 🩺 Doctor Dashboard
- Manage patient appointments
- Access patient details
- Provide consultations and updates

### 🛠 Admin Panel
- Manage user & doctor accounts
- Oversee system activity
- Ensure platform security

## ⚡ Getting Started

### 1️⃣ Clone the Repository
```bash
git clone https://github.com/AdhwaithAS/sehatsetu.git
cd sehatsetu
````

### 2️⃣ Install Dependencies

```bash
npm install
```

### 3️⃣ Set Environment Variables

Create a `.env` file in the root directory:

```
DATABASE_URL=your_database_url
JWT_SECRET=your_secret
SUPABASE_URL=your_supabase_url
SUPABASE_KEY=your_supabase_key
```

### 4️⃣ Run Development Server

```bash
npm run dev
```
